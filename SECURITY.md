# Security

Report vulnerabilities privately through the repository's GitHub security advisory flow when available. Do not post private virtual-host names, configuration dumps, credentials or health URLs in public issues.

Only fixed read-only `apachectl` options are allowed; commands execute as argument lists without a shell. The process account's filesystem permissions control what configuration it can inspect. The HTTP probe URL comes from operator configuration and never from an agent tool parameter. Response bodies are not returned. TLS validation is enabled by default. The first slice has no Apache write operation.
